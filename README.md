## 🧬 How This Portfolio Was Engineered

This section is the **engineering autopsy** of AETHERIS // 01 itself.

### The Design Philosophy — *Three Non-Negotiables*

Before writing a single line of code, three rules were set:

1. **No Frameworks.** No React, no Vue, no Tailwind, no GSAP, no Framer Motion. Just ES2023, the DOM, and the Canvas.
2. **No External Assets.** No `.glb` models, no `.mp3` audio, no `.png` textures. Everything generated at runtime.
3. **No Credential Inflation.** Zero fake client logos, zero "10K+ users" claims, zero imaginary awards. Every claim maps to a real repository.

If any of these three rules broke, the design was rejected and redone.

### The Two-Plane Rendering Model

Most "3D" portfolios fake it. AETHERIS doesn't. It runs **two independent rendering planes** stacked on top of each other:

| Plane | Technology | Purpose |
| :--- | :--- | :--- |
| **Foreground** | Semantic HTML5 + CSS design tokens | Accessible, scannable, WCAG 2.1 compliant. Text is real text. |
| **Background** | Three.js WebGL canvas | 100% procedural 3D — dodecahedron hyper-core, double-torus, 600-particle storm |

The DOM never lags. The WebGL never blocks. They coexist at 60 FPS on mid-range hardware because of one non-obvious trick: **the WebGL loop only updates when it's visible** (IntersectionObserver) and **particle counts auto-scale based on `navigator.hardwareConcurrency`**.

### The Procedural 3D Core

Not a single 3D model file is loaded. Instead, at page load:

```javascript
// Simplified — the actual engine is longer
const geo = new THREE.DodecahedronGeometry(2.4, 1);
const mat = new THREE.MeshStandardMaterial({ wireframe: true });
const core = new THREE.Mesh(geo, mat);

// 600-particle storm — all coordinates in JS, no binary
for (let i = 0; i < 600; i++) {
  particles[i] = {
    x: Math.random() * 20 - 10,
    y: Math.random() * 20 - 10,
    z: Math.random() * 20 - 10,
    vx: (Math.random() - 0.5) * 0.02,
    // ...
  };
}
```

This is why the **3D asset download is 0.00 KB**. The GPU generates everything. No network request is made for the visual layer — ever.

### The Sensory Layer — Feel Over Flash

The site *reacts*. Not with flashy over-the-top animation, but with micro-responses:

- **Magnetic reticle** — The custom cursor uses a **spring physics simulation** (`F = -kx - cv`) so it doesn't just follow the mouse — it *catches* it. Boundary detection morphs the reticle into a bracket when it hits a clickable element.
- **Parallax tilt** — The 3D layer tilts based on the mouse position using `requestAnimationFrame` delta, not event frequency. This gives a consistent feel on 60 Hz and 144 Hz displays.
- **Oscilloscope** — Not a fake animation. It reads the **live Web Audio AnalyserNode** buffer and plots actual frequency data. If music plays, the waveform moves. If not, it's flat.
- **Procedural audio** — Every sound (cursor click, menu open, sub-bass impact) is synthesized on demand using `OscillatorNode` and `GainNode`. **Zero bytes of audio** are ever downloaded.

### The Cinematic Intro (AETHERIS // 01)

Before the portfolio loads, a **~14-second fully-canvas cinematic** plays:

1. **Black screen** — pure silence, 1 second of stillness. This is intentional pacing.
2. **Character fade-in** — A cyberpunk operative walks in from the left, carrying a glowing briefcase.
3. **Deployment** — He stops, casts cyber-magic, a black table rises from the ground, the briefcase flies to it and opens with neon steam.
4. **Boot sequence** — A holographic terminal rises from the bag, matrix rain begins, `DECRYPTING...` → `WALEED RAJPOOT IDENTIFIED`.
5. **The user clicks "INITIALIZE SYSTEM"** — Gravity singularity effect. The character, table, terminal, and matrix lines are all sucked into the briefcase in a spiral implosion.
6. **The bag snaps shut** — `*CLICK!*` sound, white flash.
7. **The universe expands** — The briefcase releases a slow-motion cyan supernova, filling the screen, then fades to black for 1.3 seconds.
8. **Portfolio opens** — The 3D living universe appears.

Every frame of the intro is drawn on the **same canvas** using the same delta-time loop — no transitions, no CSS animations, no video files. **Every particle, character joint, and shockwave ring is procedural.**

The audio is 100% synthesized via `Web Audio API` — briefcase latch click, hologram hum, typing beeps, implosion whoosh, blast boom — all procedural, zero `.mp3` files, zero network bytes.

### The Admin Studio — Air-Gapped by Design

The portfolio has a **private content management plane** that runs on `localhost:4000` only:

```powershell
# Start the private local control plane
.\start-admin.bat
```

- **Zero npm install** — Powered entirely by native Node.js core modules (`http`, `fs`, `path`).
- **Air-gapped privacy** — Runs only on `http://localhost:4000`. Excluded from public Git tracking via `.gitignore`.
- **Content-sync** — Updates project records, video walkthroughs, and architecture schemas without touching source code.
- **No CMS dependency** — No Strapi, no Sanity, no Contentful, no paid backend.

No build step. No bundler. No `node_modules` at deploy time. Just static files, served from GitHub Pages, forever free.

### The Deployment Philosophy

- **Hosting:** GitHub Pages · $0/month · forever.
- **Build step:** None. `git push` → live.
- **CI/CD:** Not needed — the code is the artifact.
- **Lock-in risk:** Zero. Plain HTML/CSS/JS + WebGL. Runs on any static host.

If GitHub disappeared tomorrow, the entire portfolio could be migrated to a $2 VPS in 15 minutes with `python -m http.server`.
